2D PIXEL WORLDS IN YOUR BROWSER

UNIFIVE is an in-browser creative studio for building 2D platformers and top-down RPG maps with visual block programming, frame-by-frame character animations, and single-file .U5 export.

LAUNCH STUDIO (FREE)

BUILT FOR 2D GAME CREATION

Place scenery, configure character poses, write game logic with puzzle blocks, and export your project in one click.

Dual Perspectives

Switch between side-scrolling platformers and 4-directional top-down maps with independent layers and assets.

Magnetic Block Scripting

Snap puzzle blocks to script movement, speech bubbles, 8-bit sound synthesis, and real-time execution loops.

Character Poses & Autoplay

Preview frame animations on hover or toggle live autoplay. Includes heroes, civilians, enemies, and wildlife.

Portable .U5 Format

Export into a single compressed .u5 file with embedded icons, live canvas thumbnails, and script trees.

Canvas Tools & Cropping

Pan and zoom freely, transform layers, and crop asset sprites with grid guides directly on the stage.

Browser-Based Workflow

Runs 100% in modern desktop and mobile browsers. Zero installation, account setup, or build steps.

TWO GAME PERSPECTIVES

Design platformers or top-down adventure maps with dedicated asset libraries.

SIDE-FACING PLATFORMER

  • Multi-layer composite city skylines, deserts, forests, and mountains
  • Side sprites: Archer, Swordsman, Wizard, Police Officer, and Raider
  • Character actions: Attack, Hurt, Jump, Run, and Shoot

TOP-DOWN RPG & ADVENTURE

  • Individual cobblestone road tiles, tropical land, and terrain props
  • Medieval castles, city buildings, dungeon chests, and torch decorations
  • 4-direction heroes and wildlife: Male Warrior, Boar, Deer, Fox, and Hare

MAGNETIC PUZZLE BLOCK CODING

Snap blocks together to program characters. Scripts execute with step-by-step visual highlights.

THE .U5 FILE FORMAT

Bundles scene data, placed assets, character scripts, and metadata into one compressed file.

Self-Contained GZIP Compressed Package

When exporting a project, UNIFIVE packages only the assets and sprites placed in your scene into base64 data URLs. Metadata, canvas preview snapshots, and application icons are embedded directly in the file.

  • Embedded pixel icon for file identification
  • Canvas snapshot thumbnail for project previews
  • World transforms, crop coordinates, and layer ordering
  • Visual script trees and project variables
  • Background Web Worker compression without main thread stalls
